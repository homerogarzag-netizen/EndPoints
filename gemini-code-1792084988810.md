Hola. Necesito que diseñes y construyas en este directorio un microservicio de API en Python, optimizado para desplegarse de forma serverless en Vercel, cuyo objetivo sea despachar datos cuantitativos de mercado a otros agentes de IA y traders algorítmicos.

Contexto del proyecto:
- Tengo un worker que ya inserta cada 5 minutos el estado del mercado en una tabla de Supabase llamada `market_logs`.
- Los datos clave disponibles en esa tabla son: `price`, `expected_move`, `vix`, `trend_status`, `centroid`, `target_close`, `predicted_direction`, `predicted_strength`, entre otros.
- Esta API debe ser de solo lectura para los datos de mercado: su trabajo es consultar únicamente el registro más reciente y entregarlo en respuestas JSON muy compactas, de baja latencia y eficientes en tokens.

Lo que debes diseñar e implementar:
1. Endpoints de la API:
   - Un endpoint para rango de volatilidad y recorrido esperado (Expected Move y niveles superior/inferior calculados al vuelo).
   - Un endpoint para régimen de mercado y sesgo direccional (VIX, tendencia y predicción).
   - Un endpoint para niveles objetivo y reversión (precio, centroide y target close).
   - Un endpoint consolidado que devuelva el resumen completo de la sesión.
   - Habilita CORS abierto para que cualquier cliente o bot pueda consultar sin restricciones.

2. Sistema de Telemetría (Sonda de demanda):
   - Implementa un mecanismo (en segundo plano / no bloqueante) para registrar cada consulta entrante en una tabla de Supabase (por ejemplo `telemetria_sonda`), guardando la fecha/hora, el endpoint consultado y el `User-Agent`.
   - Si el registro de telemetría llega a fallar, la API nunca debe romperse; debe entregar el dato solicitado con máxima prioridad.

3. Preparado para Agentes de IA:
   - Genera un archivo `llms.txt` claro y conciso en la raíz para que motores de IA puedan indexar y entender cómo consumir la API.
   - Aprovecha la documentación automática interactiva (Swagger/OpenAPI).

4. Entorno y Despliegue:
   - Estructura los archivos respetando las convenciones de Vercel para Serverless Functions en Python (por ejemplo, carpeta `api/` y archivo `vercel.json`).
   - Crea `requirements.txt` solo con las dependencias estrictamente necesarias.
   - Crea `.env.example` indicando las variables de Supabase requeridas.
   - Asegúrate de que el proyecto se pueda probar de forma local antes de subirlo a Vercel.
